## 🚀 Getting Started

### Prerequisites

- Node.js 20+
- npm or yarn

### Installation

```bash
git clone https://github.com/Gehan-Atapattu/dhanodya-web-pub.git

cd dhanodya-web-pub

npm install
```

### Run Development Server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
